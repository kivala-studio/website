# M1 release gate — public site

M1 is W0–W5: landing, legal pages, public market, news, lessons and the shared portfolio page. It can replace the current site on `invest.ao` once every box below is ticked.

No preview deployment exists yet. Items marked "local" were checked on a local production build (`npm run build && npm run start`, `NEXT_PUBLIC_DATA_MODE=demo`) in the W5 pull request; repeat them on the preview before going live.

## Checklist

### Before the preview

- [x] `npm run check` and `npm run e2e` pass on a local production build (local)
- [x] Lighthouse mobile on `/mercado/[symbol]`: performance ≥ 90, accessibility ≥ 95 (local)
- [x] Share page checked against the local backend stack: valid token renders, revoked token shows the not-found state (local)

### On the preview

- [ ] Vercel project created; production env vars set (`SITE_URL`, data mode, Supabase public URL and anon key)
- [ ] `/policy` returns 200 at that exact path, with no redirect, and its text matches the App Store privacy URL
- [ ] `/partilha/[token]` with a real share created in the app: positions render signed out; a revoked share shows "Link indisponível"
- [ ] `/partilha/*` response headers: `Cache-Control: no-store`, `Referrer-Policy: no-referrer`, `X-Robots-Tag: noindex, nofollow`
- [ ] No `/partilha/*` URL in the sitemap, the Vercel request logs' analytics view or crash reports (route template only)
- [ ] `/sitemap.xml` and `/robots.txt` use the production `SITE_URL`
- [ ] Rich-results test passes for one article and one instrument page
- [ ] Lighthouse mobile on `/mercado/[symbol]` repeated on the preview
- [ ] Every redirect below returns 308 to its target

### Go-live

- [ ] Owner approves the redirect map
- [ ] `invest.ao` DNS points at the Vercel project; HTTPS certificate issued
- [ ] Spot check after the switch: `/`, `/policy`, `/mercado`, one instrument, one article, one share link
