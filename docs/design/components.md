Everything exported from `src/ui`. Feature-specific components live in `src/features` and are described in the feature documents. The gallery at `/dev/design` renders these components (`src/features/design-gallery`).

## Card and Panel

- `Card`: the surface for actions, grouped input and supporting information. With a `title` it gets a header row; `flush` lets tables and row lists reach the edges. On desk it is the `panel` surface with 24 px corners and 24 px padding.
- `Panel`: a titled section on the `panel` surface.
- `MessageCard`: a page that is one message and its actions (sign-in, not found, maintenance), centred on the canvas.

## Icons

- `Icon` renders an icon by name with an optional accessible `label` and a `scale` (`src/ui/icons/icon.tsx`).
- `src/ui/icons/icon-pack.ts` is generated by `npm run icons` from `design/icon-pack/masters.json` (a 24-unit grid with 2-unit round strokes). It holds 57 icons. Do not edit it by hand.
- `LanguageFlag` (`src/ui/icons/flags.tsx`).
- The brand mark is `public/brand/palanca.png`, used as a CSS mask so it takes the text colour (`PalancaMark` in `src/features/site/chrome.tsx`).

## Formatting in components

`useFormat` (`src/ui/format.ts`) gives client components the formatter from `src/domain/format`. See [../i18n.md](../i18n.md).
